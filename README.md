# 💍 أورما | ORMA — متجر الفضة الإسترليني عيار 925
> **Elegance That Leaves A Mark • مجوهرات فضة إسترليني إيطالية عيار 925**

متجر إلكتروني فاخر وعصري مبني بأحدث تقنيات الويب العالمية (**Next.js 14 App Router, TypeScript, Tailwind CSS**)، مصمم وفق فلسفة **الفخامة الهادئة (Quiet Luxury)** لعلامة المجوهرات الفضية المصرية **«أورما | ORMA»**.

---

## ✨ المميزات الرئيسية للمتجر

### 1. تصميم فاخر وتجربة مستخدم عالمية (Quiet Luxury UX)
- **لوحة ألوان راقية**: درجات العاجي والأوف وايت الدافئة (`#FDFBF7`) مع تباين أسود كلاسيكي وحدود رفيعة (`Hairline Borders`).
- **شريط إعلانات متحرك لا نهائي (Marquee Live Ticker)**: مع عداد تنازلي حي لعروض الموسم، شحن مجاني لكافة محافظات مصر فوق 2,500 ج.م، ونسخ فوري لكوبونات الخصم (`ATHAR10`).
- **بنر مزدوج إيديتوريال (Women's & Men's 50/50)**: مع زر `VIEW ALL` للتنقل السريع لكامل التشكيلة.
- **كروت منتجات تفاعلية**: مع ميزة تبديل الصورة التلقائي عند التمرير بالماوس (`Dual-Image Hover Swap`) وشريط إجراءات صاعد.

### 2. صفحات متعددة مستقلة (Multi-Page Routing)
- **الصفحة الرئيسية (`/`)**: بنر الهيرو، البنر المزدوج، كتالوج المنتجات، قصة البراند، دليل العناية، وآراء العملاء.
- **صفحات التشكيلات (`/collection/[slug]`)**:
  - `/collection/women`: التشكيلة النسائية مع بنر خاص.
  - `/collection/men`: التشكيلة الرجالية والعقيق اليماني.
  - `/collection/rings`: خواتم وسوليتير 925.
  - `/collection/chains`: سلاسل إيطالي ودلايات.
  - `/collection/bracelets`: أساور وتنس.
  - `/collection/sets`: أطقم ملكية وهدايا.
  - `/collection/all`: كافة القطع مع الفلترة والترتيب.
- **صفحة تفاصيل المنتج المستقلة (`/product/[id]`)**:
  - معرض صور تفاعلي مع مصغرات وشارات الفضة 925.
  - محدد نوع الطلاء والتشطيب (فضة 925 نقية، مطلي ذهب 18K، مطلي روز جولد).
  - محدد المقاسات مع زر سريع لدليل المقاسات.
  - زر الإضافة للسلة الفوري مع فتح الدرور الجانبي.
  - **زر الطلب المباشر عبر واتساب** مع رسالة مجهزة تلقائياً بكافة تفاصيل القطعة وصورتها.
  - بطاقات الثقة وقوائم أكورديون قابلة للتوسيع للمواصفات والشحن والعناية.
  - قسم الاقتراحات الذكية (You May Also Like).

### 3. منظومة التجارة الإلكترونية المصرية المتكاملة
- **سلة التسوق الجانبية (Cart Drawer)**: مع شريط تقدم نحو الشحن المجاني ومحرك الخصومات التلقائي.
- **قائمة المفضلة (Wishlist Drawer)**: حفظ واسترجاع القطع المفضلة بنقرة واحدة.
- **حاسبة الشحن المصري (Checkout Modal)**:
  - جدول أسعار شحن لكافة محافظات مصر (القاهرة، الجيزة، الإسكندرية، الدلتا، القناة، والصعيد).
  - طرق الدفع: **الدفع عند الاستلام (COD)**، **فودافون كاش**، و**إنستاباي (InstaPay)**.
  - خانة كتابة كارت الإهداء والتغليف المخملي المجاني.
- **دليل مقاسات الخواتم التفاعلي**: حساب المقاس من محيط الإصبع بالمليمتر ومطابقته بالمقاسات المصرية والأمريكية.
- **تنبيهات فخمة (Luxury Toast Notifications)** لكل إجراء.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router & Server-Side Rendering)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations & Effects**: CSS Keyframes, Hardware-accelerated Transitions, [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Fonts**: Google Fonts (`Cairo` & `Alexandria`)

## 🚀 كيفية تشغيل المشروع محلياً (Getting Started)

### المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### خطوات التشغيل:

```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل سيرفر التطوير
npm run dev

# 3. فتح المتصفح على:
# http://localhost:3000
```

### لبناء نسخة الإنتاج (Production Build):

```bash
# بناء التطبيق
npm run build

# تشغيل نسخة الإنتاج
npm start
```
